# 🍨 Ice Cream Kids Cooking (iOS Edition) 🍦

A native SwiftUI cooking game for kids (ages 2-5).

## Features
- 🍨 **5 Dessert Stations**:
  - Soft Serve Swirl Ice Cream
  - Gelato 3-Scoop Waffle Cone
  - Crispy Fruit Popsicle
  - Sweet Ice Shaved Dish
  - Fruit Milkshake Smoothie
- 🐻 **Cute Animal Customers**: Panda, Fox, Kitty, Bunny, Puppy
- 📷 **Baby's Sweet Memory Album**: Save and view beautiful ice cream creations
- 💯 **100% Free**: No paywalls, no locks
- 🌍 **100% English**: Fully accessible UI
- 🍎 **iOS Native**: SwiftUI + AVFoundation sound engine

## Build Instructions
Built automatically with GitHub Actions (`macos-14` + `swiftc`). Output IPA is signed via Sideloadly / AltStore / TrollStore for iPhone & iPad.
